# Zachary Sargent

**Founder & Sole Engineer | CodeAtlas**

I'm the founder and engineer behind **CodeAtlas**, an independently developed software analysis product.

## Building CodeAtlas

CodeAtlas is a local-first, deterministic Python static analyzer for Java and Spring repositories.

It's designed to help software modernization teams understand unfamiliar codebases through evidence-backed findings covering architecture, dependencies, entry points, persistence, integrations, configuration, and technical risks.

My focus is on building software that produces verifiable, actionable findings while preserving source privacy and making uncertainty explicit.

*CodeAtlas is under active development. Its proprietary source code remains private.*
